## Experimental approach

My research practice connects modeling, implementation and validation. I distinguish trajectory error from localization accuracy, software stopping from physical braking, training loss from generalization, and synthetic results from hardware evidence. I use baselines and failure cases to identify which conclusions an experiment supports and which need further testing.
